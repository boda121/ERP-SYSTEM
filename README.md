# 🏗️ ERP System - Under Development

## ⚠️ Project Status
This project is currently **under development**. Features are being added and improvements are ongoing.

---

## 💻 Description
This is an **ERP System** for managing an e-commerce platform.  
It includes modules for:

- Orders & Sales
- Purchase Management
- Inventory Tracking (IN / OUT)
- Invoice System
- Audit Logs

> Note: The project is not yet complete, more features will be added progressively.

---

## 🛠️ Technologies Used
- **Backend:** ASP.NET Core Web API  
- **Database:** SQL Server  
- **Architecture:** Repository Pattern, Unit of Work, Service Layer  
- **Mapping:** AutoMapper

---

## 🔥 Features Implemented So Far
- Creating Orders
- Generating Sales Invoices
- Basic Inventory Management
- Audit Logging
